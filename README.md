## 概要(Description)
この課題は42cursusの課題です。get_nextline関数を実装します。get_next_line関数とは、ファイルディスクリプタを引数として受け取り、呼び出すごとにファイルディスクリプタから一行ずつを読み取って返す関数です。ファイルの読み書きと静的変数を理解して使用できるようになるなどの事や自作ライブラリにprintf関数を実装する事を目的としています。

## 指示(Instructions)
全てのソースファイルは、`-Wall -Wextra -Werror` フラグを用いて `cc` でコンパイルされます。
`cc -Wall -Wextra -Werror -D BUFFER_SIZE=42 <files>.c`のようにコンパイルします。
`-D`フラグによって、`BUFFER_SIZE`を指定できます。指定しない場合、`BUFFER_SIZE`は`42`になります。

## Algorithm Explanation (アルゴリズムの解説と根拠)

本実装では、文字単位でのバッファリングを行うアーキテクチャを採用しています。

### 1. `ft_get_c` (バッファ付き文字取得関数)
* 静的バッファ（static buffer）を使用し、`BUFFER_SIZE` に基づいて動的にメモリを確保します。
* `read()` システムコールを呼び出すのは、現在のバッファが空になったときのみ（`i >= n`）に制限することで、システムコールの回数を最小限に抑えています。
* 静的変数（`str`, `n`, `i`）により、関数呼び出し間での読み取り状態を保持します。
* EOF（`n == 0`）やエラー（`n == -1`）が発生した際は、適切に静的メモリを解放してメモリリークを防ぎます。

### 2. `ft_put_c` & `get_next_line` (行の組み立て)
* 改行文字（`\n`）またはEOFに到達するまで、文字を1つずつ取得します。
* 取得した文字を動的に構築される文字列に追加し、最後にヌル終端文字 (`\0`) を付与して1行を完成させます。
